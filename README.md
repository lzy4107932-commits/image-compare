# 图片对比工具（Image Compare）

一款用于快速单图查看、A/B图比较两张图片差异、多图对比查看的桌面应用。

## 功能特点

- 支持导入两张图片进行对比
- 支持并排查看图片
- 支持滑块对比模式
- 支持查看图片细节
- 简洁直观的桌面操作界面
- 中英文界面
- 三色主题(深色/灰色/浅色)

## 安装与运行

确保电脑已经安装 Node.js，然后执行：

```bash
npm install
npm run dev
```
