图片对比工具 macOS 版安装说明
================================

适用设备
--------
Apple Silicon Mac：M1、M2、M3、M4 及后续 ARM64 芯片。
当前安装包不适用于 Intel Mac。

安装步骤
--------
1. 双击打开 Image-Compare-1.2.0-macOS-arm64.dmg。
2. 将“图片对比工具”拖入“应用程序”文件夹。
3. 在 Finder 的“应用程序”中打开“图片对比工具”。

首次打开提示
------------
本工具没有购买 Apple Developer ID 证书，也没有提交 Apple 公证。
第一次打开时，macOS 可能阻止应用启动。这不代表安装包损坏。

请按以下步骤操作：
1. 尝试打开一次“图片对比工具”，然后关闭系统提示。
2. 打开“系统设置”。
3. 进入“隐私与安全性”。
4. 向下找到关于“图片对比工具”被阻止的提示。
5. 点击“仍要打开”（部分系统版本可能显示“仍要安装”）。
6. 输入 Mac 登录密码或使用 Touch ID，并再次确认打开。

也可以先在 Finder 的“应用程序”中按住 Control 点击“图片对比工具”，
选择“打开”，再根据系统提示确认。

安全说明
--------
- 安装包使用免费的 macOS ad-hoc 技术签名，以保证应用结构完整。
- 该签名不是付费 Apple Developer ID 签名，因此首次打开仍会出现系统安全确认。
- 不需要、也不建议全局关闭 macOS Gatekeeper。
- 软件完全在本地处理图片，不会把图片上传到网络。

卸载
----
在“应用程序”文件夹中将“图片对比工具”移到废纸篓即可。
